Privacy policy

Kindle Desk Dashboard is a personal project used only by its owner.

What it accesses

With the owner's permission it reads the owner's Google Tasks (read-only access, scope tasks.readonly). It cannot create, change or delete tasks.

How the data is used

Task titles and due dates are used only to draw a dashboard image that is shown on the owner's own Kindle, on the owner's home network.

Storage and sharing

Data is processed on the owner's own computer. It is not sold, shared with third parties, used for advertising, or sent to any server other than Google's own APIs. The sign-in token is stored only on that computer.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions.
